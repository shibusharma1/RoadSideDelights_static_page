# RoadSideDelights_Static_Page

A **static web design project** showcasing the UI/UX and layout for **RoadSide Delights** — a responsive landing page concept for a food/roadside eatery.

This repository contains the complete static HTML and CSS files used to build the design, ready for preview, improvement, and reuse in real projects.

## 🎯 Project Overview

**RoadSideDelights_Static_Page** is a fully static front-end prototype for a roadside food website. It focuses on layout, responsiveness, and visual appeal — ideal for presenting menu highlights and engaging visitors.

This design is perfect for:

- Landing page for food stalls or street food brands  
- UI/UX web practice  
- Starting point for a dynamic restaurant site
